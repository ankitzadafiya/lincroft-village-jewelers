# Lincroft UI — Bright jewelry redesign

## References
- **Ana Luisa** — bright ivory ground, soft rounded posters, lowercase logo, pill CTAs, airy whitespace
- **Tanishq** — category explore, trending, editorial banners, occasions, visit CTA

## Visual system
- Ground: warm ivory `#fbfaf8` / soft cream
- Type: **Outfit** (logo/display) + **DM Sans** (UI/body)
- Radius: soft 16–22px posters, pill buttons
- Promo bar: light gray (not black)

## Home structure
1. Rounded auto-rotating hero poster (contained, ~58vh)
2. Circular category rail (Ken Burns / spotlight rotate)
3. Best sellers product grid (auto-rotating card images)
4. Dual editorial banners
5. Just arrived
6. Occasions (Bridal / Everyday / Gifting)
7. Visit consultation card
8. Light footer

## Auto-rotate
- Hero slides every 5s
- Product cards cycle `rotatingImages` every 3.2s (pause on hover)
- Category tiles gentle zoom/rotate + spotlight pulse
